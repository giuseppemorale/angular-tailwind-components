# Accordion

`TailwindAccordion` stacks collapsible panels; each `tailwind-accordion-item` carries its own heading and projected content.

---

## Import

```typescript
import { TailwindAccordion, TailwindAccordionItem } from 'angular-tailwind-components';
```

## Example

<Canvas of={AccordionStories.Usage} />

```typescript
@Component({
  imports: [TailwindAccordion, TailwindAccordionItem],
  template: `
    <tailwind-accordion>
      <tailwind-accordion-item title="What is Angular?">
        Angular is a platform and framework for building client-side applications using HTML, CSS, and TypeScript.
      </tailwind-accordion-item>
      <tailwind-accordion-item title="What is Tailwind CSS?">
        Tailwind CSS is a utility-first CSS framework for rapidly building custom user interfaces.
      </tailwind-accordion-item>
      <tailwind-accordion-item title="How do I get started?">
        Install the library via npm and import the components you need in your Angular module or standalone component.
      </tailwind-accordion-item>
    </tailwind-accordion>
  `
})
export class PageComponent {}
```

## Custom header

Project content into `[tailwind-accordion-header]` to replace the plain `title`: avatars, thumbnails, badges or custom-formatted text. Items without the slot keep rendering `title`.

<Canvas of={AccordionStories.CustomHeader} />

```html
<tailwind-accordion-item>
  <span tailwind-accordion-header>
    <img src="/avatars/ada.png" alt="" class="size-8 shrink-0 rounded-full" />
    <span class="flex flex-col">
      <span class="font-semibold text-neutral-900">Ada Lovelace</span>
      <span class="text-xs font-normal text-neutral-500">Analytical Engine · 3 notes</span>
    </span>
  </span>
  Wrote the first algorithm intended to be carried out by a machine.
</tailwind-accordion-item>
```

The slot is rendered **inside the trigger `<button>`**, so its text becomes the button's accessible name:

- Use phrasing content only (`span`, `strong`, `img`, `tailwind-badge`, …): no links, buttons or other interactive elements.
- Give meaningful images an `alt`; use `alt=""` for decorative ones already described by the adjacent text.
