# Alert

`TailwindAlert` mostra un messaggio con colore semantico, icona, titolo opzionale, chiusura e area azioni proiettate.

---

## Utilizzo

```typescript
@Component({
  imports: [TailwindAlert],
  template: ` <tailwind-alert color="info" title="Information" [dismissible]="true">
    This is an informational alert.
  </tailwind-alert>`
})
export class ExampleComponent {}
```

## Varianti

`kind` sceglie il peso della superficie. In modalità `bordered` il bordo non è un contorno ma una
banda accento a sinistra, che mantiene il colore semantico anche quando il riempimento è `solid`.
