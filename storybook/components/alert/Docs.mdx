# Alert

`TailwindAlert` shows a message with a semantic color, an icon, an optional title, a dismiss button and a projected actions area.

---

## Import

```typescript
import { TailwindAlert } from 'angular-tailwind-components';
```

## Properties

<ArgTypes of={AlertStories} />

Body and actions are projected content. Put the buttons on an element carrying the `tailwind-alert-actions` attribute — the same pattern as `tailwind-card-header`.

---

## Example

<Canvas of={AlertStories.Alert} />

```typescript
@Component({
  imports: [TailwindAlert],
  template: ` <tailwind-alert color="info" title="Information" [dismissible]="true">
    This is an informational alert.
  </tailwind-alert>`
})
export class ExampleComponent {}
```

## Variants

`kind` picks the weight of the surface. In `bordered` the border is not an outline but an accent band
on the left, which keeps the semantic color readable even when the fill is `solid`.
