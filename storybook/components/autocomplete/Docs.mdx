# Autocomplete

`TailwindAutocomplete` è un campo typeahead con pannello suggerimenti, `ControlValueAccessor` (il valore del form si aggiorna **solo** alla selezione di un'opzione), output `onSearch` per ricerche async e template opzionale `#item`.

---

## Utilizzo

### Lista statica (filtro locale)

```typescript
@Component({
  imports: [TailwindAutocomplete],
  template: `
    <tailwind-autocomplete
      label="Paese"
      placeholder="Cerca paese..."
      [options]="countries"
      [(value)]="countryCode"
    />`
})
export class ExampleComponent {
  countryCode: string | null = null;
  countries = [
    { value: 'IT', label: 'Italia' },
    { value: 'FR', label: 'Francia' },
  ];
}
```

### Ricerca async

Con `[filterLocally]="false"` il componente mostra le `options` fornite dal parent; su `(onSearch)` aggiorni l'elenco (es. chiamata HTTP).

```typescript
onSearch(query: string) {
  this.filteredOptions = this.allCountries.filter(c =>
    c.label.toLowerCase().startsWith(query.toLowerCase())
  );
}
```

<Canvas of={AutocompleteStories.AsyncSearch} />

### Template opzione (`#item`)

Nessuna direttiva: proietta un `ng-template` con reference `#item`.

```html
<tailwind-autocomplete [options]="countries" [(value)]="code">
  <ng-template let-option #item>
    <span class="flex items-center gap-2">
      <span class="font-mono text-xs">{{ option.value }}</span>
      <span>{{ option.label }}</span>
    </span>
  </ng-template>
</tailwind-autocomplete>
```

Variabili di context: `let-option` (`$implicit`), `let-index="index"`, `let-selected="selected"`, `let-active="active"`.

### `TailwindAutocompleteItemContext<T>`

```typescript
interface TailwindAutocompleteItemContext<T = unknown> {
  $implicit: TailwindOption<T>;
  option: TailwindOption<T>;
  index: number;
  selected: boolean;
  active: boolean;
}
```
