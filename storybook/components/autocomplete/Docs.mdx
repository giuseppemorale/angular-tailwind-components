# Autocomplete

`TailwindAutocomplete` is a typeahead field with a suggestion panel, a `ControlValueAccessor` whose form value changes **only** when an option is picked, an `onSearch` output for async lookups and an optional `#item` template.

---

## Import

```typescript
import { TailwindAutocomplete } from 'angular-tailwind-components';
```

## Properties

<ArgTypes of={AutocompleteStories} />

### `TailwindAutocompleteItemContext<T>`

```typescript
interface TailwindAutocompleteItemContext<T = unknown> {
  $implicit: TailwindOption<T>;
  option: TailwindOption<T>;
  index: number;
  selected: boolean;
  active: boolean;
}
```

## Example

### Static list (local filtering)

```typescript
@Component({
  imports: [TailwindAutocomplete],
  template: ` <tailwind-autocomplete
    label="Paese"
    placeholder="Search a country..."
    [options]="countries"
    [(value)]="countryCode" />`
})
export class ExampleComponent {
  countryCode: string | null = null;
  countries = [
    { value: 'IT', label: 'Italia' },
    { value: 'FR', label: 'Francia' }
  ];
}
```

### Async search

With `[filterLocally]="false"` the component renders whatever `options` the parent provides; refresh that list from `(onSearch)`, typically with an HTTP call.

```typescript
onSearch(query: string) {
  this.filteredOptions = this.allCountries.filter(c =>
    c.label.toLowerCase().startsWith(query.toLowerCase())
  );
}
```

### Option template (`#item`)

No directive involved: project an `ng-template` with the `#item` reference.

```html
<tailwind-autocomplete [options]="countries" [(value)]="code">
  <ng-template let-option #item>
    <span class="flex items-center gap-2">
      <span class="font-mono text-xs">{{ option.value }}</span>
      <span>{{ option.label }}</span>
    </span>
  </ng-template>
</tailwind-autocomplete>
```

Context variables: `let-option` (`$implicit`), `let-index="index"`, `let-selected="selected"`, `let-active="active"`.
