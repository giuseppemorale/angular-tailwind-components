# Avatar

`TailwindAvatar` shows a profile image, the initials derived from `name`, or a fallback icon, with an optional status dot.

---

## Import

```typescript
import { TailwindAvatar } from 'angular-tailwind-components';
```

## Properties

<ArgTypes of={AvatarStories} />

---

## Example

<Canvas of={AvatarStories.Avatar} />

```typescript
@Component({
  imports: [TailwindAvatar],
  template: ` <tailwind-avatar name="John Doe" size="md" status="success" /> `
})
export class ExampleComponent {}
```
