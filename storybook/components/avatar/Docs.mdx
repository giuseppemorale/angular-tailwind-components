# Avatar

`TailwindAvatar` mostra un'immagine profilo, le iniziali derivate da `name` o un'icona fallback, con indicatore di stato opzionale.

---

## Utilizzo

```typescript
@Component({
  imports: [TailwindAvatar],
  template: `
    <tailwind-avatar name="Giuseppe Morale" size="md" status="success" />
  `
})
export class ExampleComponent {}
```
