# Badge

`TailwindBadge` è un’etichetta compatta con varianti di colore, dimensione e opzione “dot”.

---

## Utilizzo

```typescript
@Component({
  imports: [TailwindBadge],
  template: `<tailwind-badge color="primary" size="md">Badge</tailwind-badge>`
})
export class ExampleComponent {}
```

## Varianti

`kind` sceglie il peso della superficie. Le tre varianti hanno **metriche identiche** (tutte
applicano un bordo, trasparente dove non serve), quindi cambiare `kind` non ridimensiona il badge.
La stessa triade è disponibile su `tailwind-chip`, `tailwind-tag` e `tailwind-alert`.
