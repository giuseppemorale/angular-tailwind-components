# Badge

`TailwindBadge` is a compact label with color, size and dot variants.

---

```typescript

```


## Variants

`kind` picks the weight of the surface. All three variants share **identical metrics** (each one
applies a border, transparent where it is not needed), so switching `kind` never resizes the badge.
The same triad is available on `tailwind-chip`, `tailwind-tag` and `tailwind-alert`.
