# Breadcrumb

`TailwindBreadcrumb` renders a hierarchy of links, with the last entry rendered as the current page instead of a link.

---

## Import

```typescript
import { TailwindBreadcrumb } from 'angular-tailwind-components';
```

## Example

<Canvas of={BreadcrumbStories.Breadcrumb} />

```typescript
@Component({
  imports: [TailwindBreadcrumb],
  template: ` <tailwind-breadcrumb
    ariaLabel="Breadcrumb"
    separator="/"
    [items]="[{ label: 'Home', link: '#', icon: 'home' }, { label: 'Section', href: '#' }, { label: 'Current' }]" />`
})
export class ExampleComponent {}
```
