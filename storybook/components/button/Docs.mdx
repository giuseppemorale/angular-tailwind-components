# Button

`TailwindButton` è il pulsante principale della libreria con colori, varianti solid/flat/outlined/ghost/text e dimensioni.

---

## Utilizzo

```typescript
@Component({
  imports: [TailwindButton],
  template: ` <tailwind-button type="button" color="primary" kind="solid" size="md" icon="plus">
    Add item
  </tailwind-button>`
})
export class ExampleComponent {}
```

## Varianti

`solid` porta un highlight interno di 1px sul bordo superiore invece di un’ombra: l’ombra significa
_elevazione_ e appartiene a card e overlay, non a ogni pulsante della pagina.

<Canvas of={ButtonStories.Kinds} />

`soft` è la variante tinta — abbastanza forte da leggersi come azione, abbastanza discreta da stare
accanto a un `solid` primario senza competere.

<Canvas of={ButtonStories.Soft} />

## Allineamento con i campi

L’altezza è fissata dalla scala condivisa (`h-6` / `h-8` / `h-9` / `h-11` / `h-13`), non derivata dal
padding verticale: un pulsante e un campo della stessa `size` sono alti esattamente uguale, anche con
icone o font diversi. Un pulsante solo-icona resta quadrato sulla stessa altezza.
