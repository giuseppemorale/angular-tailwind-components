# Button

`TailwindButton` is the main button of the library, with semantic colors, the solid/flat/outlined/ghost/text variants and the shared size scale.

---

## Import

```typescript
import { TailwindButton } from 'angular-tailwind-components';
```

## Variants

`solid` carries a 1px inner highlight on its top edge instead of a shadow: a shadow means
_elevation_ and belongs to cards and overlays, not to every button on the page.

<Canvas of={ButtonStories.Kinds} />

`soft` is the tinted variant — strong enough to read as an action, quiet enough to sit next to a
primary `solid` without competing with it.

<Canvas of={ButtonStories.Soft} />

## Aligning with form fields

Height comes from the shared scale (`h-6` / `h-8` / `h-9` / `h-11` / `h-13`), not from vertical
padding: a button and a field of the same `size` are exactly as tall, whatever their icons or fonts.
An icon-only button stays square at that same height.
