# Calendar Panel

`TailwindCalendarPanel` is an inline calendar for picking a **date** (`Date | null`). It is a `ControlValueAccessor`, so it works with reactive forms and `ngModel`.

Use it when you only need the grid, with no input field — in dialogs, filter bars or custom layouts. For a field with a popover, use **`TailwindDatePicker`**.

---

## Import

```typescript
import { ReactiveFormsModule, TailwindCalendarPanel } from 'angular-tailwind-components';

}
```

```html
<tailwind-calendar-panel [(value)]="selectedDate" />
```

## Navigation

- **Arrows**: previous/next month in the day view, or the previous/next block of 12 years in the year view.
- **Header** (e.g. `May 2026`): opens the **years** grid → then **months** → back to days.
- **Today**: jumps to the current month and selects today, updating the form value immediately. When today falls outside `minDate`/`maxDate` the button stays visible but disabled.

Picking a day updates the value immediately — there is no Apply button.

## Embedded use inside the pickers

**DatePicker** and **DateTimePicker** set `embedded` to `true` on the panel through `ViewChild` when the popover opens. In that mode the calendar never writes to the CVA on its own: it emits `(daySelect)` and reads `highlightDate` for the parent draft, which owns the Today / Apply footer.

## Language

Like DatePicker and DateTimePicker, it reads the **`TAILWIND_DATETIME_LANGUAGE`** token (`'it'` | `'en'`, default `'it'`).
