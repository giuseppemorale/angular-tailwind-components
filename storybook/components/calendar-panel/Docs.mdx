# Calendar Panel

`TailwindCalendarPanel` è un calendario inline per la selezione di una **data** (`Date | null`). È un `ControlValueAccessor` e si integra con reactive forms e `ngModel`.

Usalo quando serve solo la griglia calendario (senza campo input), ad esempio in modali, filtri o layout personalizzati. Per un campo con popover usa **`TailwindDatePicker`**.

---

## Utilizzo

```typescript
@Component({
  imports: [TailwindCalendarPanel, ReactiveFormsModule],
  template: `
    <tailwind-calendar-panel [formControl]="birthDate" />
  `
})
export class ExampleComponent {
  birthDate = new FormControl<Date | null>(null);
}
```

Two-way binding con `value`:

```html
<tailwind-calendar-panel [(value)]="selectedDate" />
```

## Navigazione

- **Frecce**: mese precedente/successivo (vista giorni) o intervallo di 12 anni (vista anni).
- **Intestazione** (es. `Maggio 2026`): apre la griglia **anni** → poi **mesi** → torna ai giorni.
- **Oggi**: porta al mese corrente e seleziona la data odierna (aggiorna subito il valore del form).

La selezione di un giorno aggiorna immediatamente il valore (nessun pulsante Applica).

---

## Modalità embedded

Con `[embedded]="true"` il pannello non gestisce il valore del form: emette solo `(daySelect)` e si aspetta `highlightDate` dal genitore. È il modo in cui **DatePicker** e **DateTimePicker** lo incorporano nel popover.

## Lingua

Come DatePicker e DateTimePicker, usa il token **`TAILWIND_DATETIME_LANGUAGE`** (`'it'` | `'en'`, default `'it'`).
