# Card

`TailwindCard` is a container with optional slots for header, body, image and footer.

---

## Import

```typescript
import { TailwindCard } from 'angular-tailwind-components';
```

## Properties

Classes passed through `class` / `[class]` land on the inner visual surface, not just on the host tag.

<ArgTypes of={CardStories} />

### Content projection

| Slot                     | How to project it                   | Description                            |
| ------------------------ | ----------------------------------- | -------------------------------------- |
| `[tailwind-card-header]` | `<div tailwind-card-header>…</div>` | Rendered only when `hasHeader` is true |
| `[tailwind-card-image]`  | `<div tailwind-card-image>…</div>`  | Full-bleed image, above the body       |
| _(default)_              | Direct children of the tag          | Card body                              |
| `[tailwind-card-footer]` | `<div tailwind-card-footer>…</div>` | Rendered only when `hasFooter` is true |

### Header and footer zones

A zone is set apart by a hairline rule **or** by the chrome fill (`surface-subtle`, a 3% tint of the
foreground) — never both, which is what made stacked headers read heavy. `headerBg` and `footerBg`
swap the rule for the fill on their zone; both default to `false`.

## Example

<Canvas of={CardStories.Card} />

```typescript
@Component({
  imports: [TailwindCard, TailwindButton],
  template: ` <tailwind-card [elevated]="false" [hoverable]="false" [hasHeader]="true" [hasFooter]="true">
    <div tailwind-card-header><h3 class="font-semibold">Title</h3></div>
    <p>Card content.</p>
    <div tailwind-card-footer>
      <tailwind-button>OK</tailwind-button>
    </div>
  </tailwind-card>`
})
export class ExampleComponent {}
```

## Density

`density` drives the padding of header, body and footer together: `comfortable` (24px) for a page
with few cards, `compact` (16px) for dashboards, where the same padding repeated across a dozen tiles
costs more space than the content it frames.

## Equal height in a grid

In a CSS grid with `align-items: stretch` (the default), add `class="h-full"` to every card: the class is forwarded to the surface and all cards in the same row share the visual height of the white box.

```html
<div class="grid gap-6 lg:grid-cols-5">
  <tailwind-card class="h-full" [hasFooter]="false">
    <div tailwind-card-header><h3 class="font-semibold">Step 1</h3></div>
    <p class="text-sm text-neutral-600">Short text.</p>
  </tailwind-card>
  <!-- other cards with class="h-full" -->
</div>
```

Avoid `items-start` on the grid if you want the heights to match. No dedicated input is needed: any Tailwind or custom class on `tailwind-card` goes through the same forwarding mechanism.
