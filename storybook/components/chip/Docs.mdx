# Chip

`TailwindChip` is a compact, removable label — for filters, tag inputs and multi-selection.

---

## Import

```typescript
import { TailwindChip } from 'angular-tailwind-components';
```

## Example

<Canvas of={ChipStories.Chip} />

```typescript
@Component({
  imports: [TailwindChip],
  template: ` <tailwind-chip color="secondary" (removed)="onRemove()"> Angular </tailwind-chip> `
})
export class ExampleComponent {
  onRemove() {
    console.log('removed');
  }
}
```

## Variants

`kind` picks the weight of the surface. The three variants share identical metrics, so switching
`kind` never resizes the chip. The same triad is available on `tailwind-badge`, `tailwind-tag` and
`tailwind-alert`.
