# Chip

`TailwindChip` è un'etichetta compatta e rimovibile, utile per filtri, tag input e selezione multipla.

---

## Utilizzo

```typescript
@Component({
  imports: [TailwindChip],
  template: `
    <tailwind-chip color="secondary" (removed)="onRemove()">
      Angular
    </tailwind-chip>
  `
})
export class ExampleComponent {
  onRemove() {
    console.log('removed');
  }
}
```
