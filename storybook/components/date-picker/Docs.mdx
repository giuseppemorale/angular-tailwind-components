# Date Picker

`TailwindDatePicker` picks a date through a calendar popover. The control value is a `Date`, and the field is a `ControlValueAccessor`.

---

## Import

```typescript
import { TailwindDatePicker } from 'angular-tailwind-components';
```

## Example

```typescript
@Component({
  imports: [TailwindDatePicker],
  template: ` <tailwind-date-picker label="Data di nascita" format="dd/MM/yyyy" [(value)]="date" />`
})
export class ExampleComponent {
  date: Date | null = null;
}
```

## Behaviour

The component follows a **draft/apply** pattern:

1. The user opens the calendar by clicking the field.
2. They move between months with the arrows or, by clicking the month/year header, step into the **year grid** (12 years per page, arrows to change range), then the **month grid**, and finally pick a day — the selection is held as a _draft_ and does not touch the form value yet.
3. **Today** jumps to the current month and preselects today in the draft.
4. **Apply** commits the draft, updates the value and closes the panel.

The form therefore only changes on an explicit user decision.

## Language

The component ships Italian (`it`) and English (`en`), selected through the `TAILWIND_DATETIME_LANGUAGE` token.

### Global configuration (recommended)

Provide the token once, at `ApplicationConfig` level:

```typescript
// app.config.ts
import { ApplicationConfig } from '@angular/core';
import { TAILWIND_DATETIME_LANGUAGE } from 'angular-tailwind-components';

export const appConfig: ApplicationConfig = {
  providers: [{ provide: TAILWIND_DATETIME_LANGUAGE, useValue: 'it' }]
};
```

### Local configuration (per component)

```typescript
@Component({
  providers: [{ provide: TAILWIND_DATETIME_LANGUAGE, useValue: 'en' }]
})
export class MyComponent {}
```

## Date formatting

The emitted value is a `Date` at local midnight, e.g. `new Date(2026, 4, 8)`.
What the field displays comes from `format` (default `dd/MM/yyyy`), rendered through Angular `formatDate`.
