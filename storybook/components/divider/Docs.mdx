# Divider

`TailwindDivider` is a reusable separator: horizontal or vertical, solid or dashed, with an optional centred label on the horizontal variant.

---

## Import

```typescript
import { TailwindDivider } from 'angular-tailwind-components';
```

## Example

<Canvas of={DividerStories.Horizontal} />

```typescript
import { Component } from '@angular/core';
import { TailwindDivider } from 'angular-tailwind-components';

@Component({
  imports: [TailwindDivider],
  template: `
    <p>Sezione A</p>
    <tailwind-divider />
    <p>Sezione B</p>
    <tailwind-divider orientation="vertical" variant="dashed" />
  `
})
export class ExampleComponent {}
```

Inside a row **flex** container, `orientation="vertical"` draws a vertical line that stretches to the row height — add `self-stretch` on the parent when needed.
