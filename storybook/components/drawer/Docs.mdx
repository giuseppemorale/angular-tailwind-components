# Drawer

`TailwindDrawer` is an animated side panel with a title and `open()` / `close()` methods.

---

## Import

```typescript
import { TailwindButton, TailwindDrawer, TailwindInput } from 'angular-tailwind-components';
```

## Example

<Canvas of={DrawerStories.Drawer} />

```typescript
@Component({
  imports: [TailwindDrawer, TailwindButton, TailwindInput],
  template: ` <div>
    <tailwind-button (click)="drawer.open()">Open drawer</tailwind-button>
    <tailwind-drawer #drawer title="Drawer Title" position="right" [closeOnBackdrop]="true">
      <p>Contenuto</p>
      <tailwind-button (click)="drawer.close()">Close</tailwind-button>
    </tailwind-drawer>
  </div>`
})
export class ExampleComponent {}
```

The optional footer is projected through the `tailwind-drawer-footer` attribute on a direct child, e.g. `<div tailwind-drawer-footer>`.
