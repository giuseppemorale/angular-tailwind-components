# Editor

`TailwindEditor` is a WYSIWYG rich-text field built with a native `contenteditable` surface and browser editing APIs — no third-party editor libraries. The form value is **sanitized HTML**. A toolbar provides formatting commands; link and image insertion use design-system modals.

---

## Import

```typescript
import { TailwindEditor } from 'angular-tailwind-components';
```

## Properties

<ArgTypes of={EditorStories} />

### Toolbar — text alignment

With the `full` preset, the four buttons after the list commands apply `text-align` to the current block (left, centre, right, justify). The form value then carries `style="text-align: …"` on the block tags; the sanitizer strips every other CSS property from `style`.

### Toolbar — the `code` command

The **code** button (`icon: code-bracket`) switches between the visual editor and a **textarea** for editing the HTML by hand. The rest of the toolbar is disabled while code mode is on.

## Example

<Canvas of={EditorStories.Editor} />

```typescript
@Component({
  imports: [TailwindEditor],
  template: ` <tailwind-editor
    label="Article body"
    placeholder="Write your content…"
    toolbar="full"
    [(value)]="body"
    (htmlChange)="onBodyChange($event)" />`
})
export class ExampleComponent {
  body = '<p>Hello <strong>world</strong></p>';

  onBodyChange(html: string): void {
    console.log('HTML updated', html);
  }
}
```

### `provideTailwindConfig` — dialog and code-view labels

```typescript
provideTailwindConfig({
  EDITOR_LABELS: {
    linkModalTitle: 'Insert link',
    cancel: 'Cancel',
    insert: 'Insert'
    // Altre chiavi: default della libreria (DEFAULT_TAILWIND_EDITOR_LABELS)
  }
});
```

## `TAILWIND_EDITOR_LABELS`

Optional token — also reachable through `provideTailwindConfig({ EDITOR_LABELS })` — for the link/image dialog titles, buttons, HTML source placeholder, accessible names (`surfaceAriaLabel`, `imageFileInputAriaLabel`) and validation messages. Defaults to `DEFAULT_TAILWIND_EDITOR_LABELS`.

## Security

The HTML is filtered against a tag and attribute allowlist: scripts, `on*` handlers and `javascript:` URLs are removed. For untrusted authors, validate on the server as well.

## Limitations

- Formatting goes through the Selection API and DOM manipulation; undo/redo uses an internal HTML stack, not `document.execCommand`.
- Tables and collaborative editing are out of scope for v1.
- Base64 images can grow the form value considerably.
