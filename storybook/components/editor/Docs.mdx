# Editor

`TailwindEditor` is a WYSIWYG rich-text field built with a native `contenteditable` surface and browser editing APIs — no third-party editor libraries. The form value is **sanitized HTML**. A toolbar provides formatting commands; link and image insertion use design-system modals.

---

## Utilizzo

```typescript
@Component({
  imports: [TailwindEditor],
  template: `
    <tailwind-editor
      label="Article body"
      placeholder="Write your content…"
      toolbar="full"
      [(value)]="body"
      (htmlChange)="onBodyChange($event)"
    />`
})
export class ExampleComponent {
  body = '<p>Hello <strong>world</strong></p>';

  onBodyChange(html: string): void {
    console.log('HTML updated', html);
  }
}
```

### `provideTailwindConfig` — etichette modali e code view

```typescript
provideTailwindConfig(() => ({
  EDITOR_LABELS: {
    linkModalTitle: 'Inserisci link',
    cancel: 'Annulla',
    insert: 'Inserisci'
    // Altre chiavi: default della libreria (DEFAULT_TAILWIND_EDITOR_LABELS)
  }
}));
```

### Toolbar — allineamento testo

Con preset <code>full</code>, i quattro pulsanti dopo elenco puntato/numerato applicano <code>text-align</code> sul blocco corrente (sinistra, centro, destra, giustifica). Il valore form include <code>style="text-align: …"</code> sui tag di blocco; il sanitizer rimuove le altre proprietà CSS da <code>style</code>.

### Toolbar — comando `code`

Il pulsante **code** (`icon: code-bracket`) alterna l’editor visuale e una **textarea** per modificare l’HTML a mano. In modalità codice gli altri comandi della toolbar sono disabilitati.

---

## `TAILWIND_EDITOR_LABELS`

Token opzionale (anche via `provideTailwindConfig` con `EDITOR_LABELS`) per titoli modali link/immagine, pulsanti, placeholder della sorgente HTML e messaggi di validazione. Default: `DEFAULT_TAILWIND_EDITOR_LABELS`.

## Sicurezza

L'HTML viene filtrato con una whitelist di tag e attributi. Script, handler `on*`, e URL `javascript:` sono rimossi. Per contenuti da utenti non fidati, validare anche lato server.

## Limiti

- Formattazione via Selection API e manipolazione DOM; undo/redo con stack HTML interno (non `document.execCommand`).
- Tabelle e editing collaborativo non sono inclusi nella v1.
- Immagini base64 possono aumentare molto la dimensione del valore form.
