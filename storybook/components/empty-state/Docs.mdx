# EmptyState

`TailwindEmptyState` is the "nothing here yet" panel: icon, title, explanation and room for a call to action.

Spacing, muted colors and heading level stay consistent across every empty list, and the icon is correctly hidden from screen readers.

---

## Import

```typescript
import { TailwindButton, TailwindEmptyState } from 'angular-tailwind-components';
```
