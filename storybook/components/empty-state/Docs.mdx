# EmptyState

`TailwindEmptyState` è il pannello "non c&apos;è ancora nulla": icona, titolo, spiegazione e spazio per una call to action.

Esiste perché ogni lista vuota non debba reinventare il proprio div centrato: spaziature, colori attenuati e livello di heading restano coerenti, e l&apos;icona è correttamente nascosta agli screen reader.

---

## Utilizzo

```typescript
@Component({
  imports: [TailwindEmptyState, TailwindButton],
  template: ` <tailwind-empty-state
    title="Nessuna fattura"
    description="Le fatture create appariranno qui."
    icon="document-text">
    <tailwind-button size="sm">Crea fattura</tailwind-button>
  </tailwind-empty-state>`
})
export class ExampleComponent {}
```
