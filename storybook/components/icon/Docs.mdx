# Icon

`TailwindIcon` mostra un’icona **Heroicons outline** tramite maschera CSS su `/tailwind-icons/<nome>.svg`.

Per l’elenco completo dei nomi disponibili vedi **[Docs → Icons](?path=/docs/docs-icons--docs)** (catalogo con ricerca e copia negli appunti).

---

## Utilizzo

```typescript
import { TailwindIcon } from 'angular-tailwind-components';

@Component({
  imports: [TailwindIcon],
  template: `<tailwind-icon icon="bell" [size]="24" class="text-primary-600" />`
})
export class ExampleComponent {}
```
