# Icon

`TailwindIcon` renders a **Heroicons outline** icon through a CSS mask over `/tailwind-icons/<name>.svg`.

For the full list of names see **[Docs → Icons](?path=/docs/docs-icons--docs)** — a searchable catalogue with copy to clipboard.

---

## Import

```typescript
import { TailwindIcon } from 'angular-tailwind-components';
```

## Example

<Canvas of={IconStories.Icon} />

```typescript
import { TailwindIcon } from 'angular-tailwind-components';

@Component({
  imports: [TailwindIcon],
  template: `<tailwind-icon icon="bell" [size]="24" class="text-primary-600" />`
})
export class ExampleComponent {}
```
