# Input Password

`TailwindInputPassword` è un campo password con supporto form (`ControlValueAccessor`), toggle opzionale per mostrare/nascondere il testo e pannello feedback con meter automatico (debole / buona / forte).

---

## Utilizzo

```typescript
@Component({
  imports: [TailwindInputPassword],
  template: `
    <tailwind-input-password
      label="Password"
      placeholder="••••••••"
      [feedback]="true"
      [toggleMask]="true"
      [formControl]="form.controls.password" />
  `
})
export class ExampleComponent {}
```

## Label globali con defineTheme

```typescript
import { defineTheme } from 'angular-tailwind-components';

defineTheme({
  PASSWORD_LABELS: {
    prompt: 'Scegli una password',
    weak: 'Debole',
    medium: 'Buona',
    strong: 'Forte'
  }
});
```
