# Input Password

`TailwindInputPassword` is a password field with form support (`ControlValueAccessor`), an optional reveal toggle and a feedback panel with an automatic strength meter (weak / good / strong).

---

## Import

```typescript
import { TailwindInputPassword } from 'angular-tailwind-components';
```

## Example

<Canvas of={InputPasswordStories.WithToggleMask} />

```typescript
@Component({
  imports: [TailwindInputPassword],
  template: `
    <tailwind-input-password
      label="Password"
      placeholder="••••••••"
      [feedback]="true"
      [toggleMask]="true"
      [formControl]="form.controls.password" />
  `
})
export class ExampleComponent {}
```

## Global labels with `provideTailwindConfig`

```typescript
import { provideTailwindConfig } from 'angular-tailwind-components';

provideTailwindConfig({
  PASSWORD_LABELS: {
    prompt: 'Choose a password',
    weak: 'Debole',
    medium: 'Buona',
    strong: 'Forte'
  }
});
```
