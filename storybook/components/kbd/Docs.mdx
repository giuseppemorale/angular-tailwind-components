# Kbd

`TailwindKbd` represents a keyboard key, using the native `<kbd>` element.

Passing `keys` renders a whole chord: the separators are `aria-hidden`, so a screen reader announces the keys and not the punctuation.

---

## Import

```typescript
import { TailwindKbd } from 'angular-tailwind-components';
```
