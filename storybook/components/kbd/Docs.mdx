# Kbd

`TailwindKbd` rappresenta un tasto della tastiera, con l&apos;elemento nativo `<kbd>`.

Passando `keys` rende un&apos;intera combinazione: i separatori sono `aria-hidden`, così lo screen reader annuncia i tasti e non la punteggiatura.

---

## Utilizzo

```typescript
@Component({
  imports: [TailwindKbd],
  template: ` Premi <tailwind-kbd [keys]="['Ctrl', 'K']" /> per cercare. Premi <tailwind-kbd>Esc</tailwind-kbd> per
    chiudere.`
})
export class ExampleComponent {}
```

## Properties
