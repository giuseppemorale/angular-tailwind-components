# Menu

`TailwindMenu` is a dropdown positioned against a toggle that stays a **sibling** of `tailwind-menu`. Pass the `click` to `open($event)` so the panel anchors under the element that emitted it (`currentTarget`). After the first anchored open, `open()` can be called with no argument and reuses the last anchor.

---

## Import

```typescript
import { TailwindButton, TailwindMenu } from 'angular-tailwind-components';
```

## Example

<Canvas of={MenuStories.Menu} />

```typescript
@Component({
  imports: [TailwindMenu, TailwindButton],
  template: ` <tailwind-button (click)="menu.open($event)">Open menu</tailwind-button>
    <tailwind-menu #menu [items]="items" align="left" (onSelect)="onSelect($event)" />`
})
export class ExampleComponent {
  items = [
    { label: 'Profile', value: 'profile' },
    { label: 'Sign out', value: 'signout' }
  ];
  onSelect(item: unknown) {}
}
```

To anchor on an explicit DOM element, call `menu.open(buttonEl)` with an `HTMLElement`.

## Methods (template ref)

| Method                                  | Description                                                                                              |
| --------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| `open(anchor?: Event \| HTMLElement)`   | Opens under the anchor. With `(click)="menu.open($event)"` on the button host, the anchor is the toggle. |
| `close()`                               | Closes the menu.                                                                                         |
| `toggle(anchor?: Event \| HTMLElement)` | Opens or closes; opening needs an anchor exactly like `open`, unless one was already set.                |
