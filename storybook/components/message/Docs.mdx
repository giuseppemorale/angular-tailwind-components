# Message

`TailwindMessage` is a compact inline message with a semantic color and projected content.

---

## Import

```typescript
import { TailwindMessage } from 'angular-tailwind-components';
```

## Properties

<ArgTypes of={MessageStories} />

The message text is projected content. The icon is not derived from `color`: pick it explicitly with `icon`.

---

## Example

<Canvas of={MessageStories.Message} />

```typescript
@Component({
  imports: [TailwindMessage],
  template: ` <tailwind-message color="info" icon="information-circle">
    This is an informational message.
  </tailwind-message>`
})
export class ExampleComponent {}
```
