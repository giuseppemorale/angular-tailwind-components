# Meter

`TailwindMeter` draws a **segmented** bar: every segment has a `label`, a `value` and an optional color. Values are normalised against **`max`** (default 100).

---

## Import

```typescript
import { TailwindMeter } from 'angular-tailwind-components';
```

## Example

<Canvas of={MeterStories.MultiSegment} />

```typescript
import { Component } from '@angular/core';
import { TailwindMeter, TailwindMeterSegment } from 'angular-tailwind-components';

@Component({
  imports: [TailwindMeter],
  template: ` <tailwind-meter [segments]="segments" [max]="100" [showLabels]="true" size="md" /> `
})
export class ExampleComponent {
  segments: TailwindMeterSegment[] = [
    { label: 'Apps', value: 40, color: 'primary' },
    { label: 'Other', value: 60, color: 'info' }
  ];
}
```

The `TailwindMeterSegment` type is exported by the library: `label`, `value` and an optional `color` of type `TailwindColor`.
