# Modal

`TailwindModal` is an overlay dialog opened through `TailwindModalService`. `open()` returns a promise that resolves with whatever was passed to `close()`, or `undefined` when the dialog is dismissed without a result.

---

## Import

```typescript
import {
  TAILWIND_MODAL_DATA,
  TailwindModalContent,
  TailwindModalFooter,
  TailwindModalRef,
  TailwindModalService,
  TailwindModalTitle
} from 'angular-tailwind-components';
```

## Properties

<ArgTypes of={ModalStories} />

Most applications never bind these directly: they come from the `TailwindModalConfig` passed to `open()`.

## Example

### 1 — Write the dialog component

The component fills three slots, addressed by attribute selectors: `tailwind-modal-title`, `tailwind-modal-content`, `tailwind-modal-footer`. Inject `TailwindModalRef<R>` to close the dialog with a typed result.

```typescript
@Component({
  imports: [TailwindButton],
  template: `
    <h4 tailwind-modal-title>Confirm action</h4>
    <div tailwind-modal-content>
      <p>This cannot be undone. Do you want to continue?</p>
    </div>
    <div tailwind-modal-footer>
      <div class="flex justify-end gap-3">
        <tailwind-button kind="outlined" (click)="ref.close()">Cancel</tailwind-button>
        <tailwind-button color="primary" (click)="ref.close(true)">Confirm</tailwind-button>
      </div>
    </div>
  `
})
export class ConfirmModalComponent {
  readonly ref = inject<TailwindModalRef<boolean>>(TailwindModalRef);
}
```

### 2 — Open it

```typescript
async deleteItem(): Promise<void> {
  const confirmed = await this.modalService.open<boolean>(ConfirmModalComponent, {
    size: 'md',
    showCloseButton: true,
  });

  if (confirmed) {
    // proceed with the deletion
  }
}
```

## Slot components

The service distributes the direct children carrying a `tailwind-modal-*` attribute into the three slots of `TailwindModal`.

- `TailwindModalTitle` — `[tailwind-modal-title]` — header, rendered inside the `<h2>`, e.g. `<span tailwind-modal-title>…</span>`
- `TailwindModalContent` — `[tailwind-modal-content]` — body, `px-6 py-5`, e.g. `<div tailwind-modal-content>…</div>`
- `TailwindModalFooter` — `[tailwind-modal-footer]` — footer, `px-6 py-4 border-t`, e.g. `<div tailwind-modal-footer>…</div>`

> Import all three in the dialog component that uses them, or use plain elements with the same attribute and skip the helper components.

## `TailwindModalRef<R>`

Injected into the dialog component by the service.

```typescript
const ref = inject<TailwindModalRef<boolean>>(TailwindModalRef);

ref.close(true); // resolves the promise with `true`
ref.close(); // resolves the promise with `undefined`
```

## Passing data to the dialog

`config.data` is injected into the dialog component through `TAILWIND_MODAL_DATA`.

```typescript
interface DeleteData {
  itemName: string;
}

@Component({
  imports: [TailwindButton],
  template: `
    <h4 tailwind-modal-title>Delete item</h4>
    <div tailwind-modal-content>
      <p>
        You are about to delete <strong>{{ data.itemName }}</strong
        >.
      </p>
    </div>
    <div tailwind-modal-footer class="flex justify-end">
      <tailwind-button color="danger" (click)="ref.close(true)">Delete</tailwind-button>
    </div>
  `
})
export class DeleteModalComponent {
  readonly ref = inject<TailwindModalRef<boolean>>(TailwindModalRef);
  readonly data = inject<DeleteData>(TAILWIND_MODAL_DATA);
}

// Caller
const deleted = await this.modalService.open<boolean>(DeleteModalComponent, {
  data: { itemName: 'Invoice #1042' }
});
```

## Configuration

```typescript
interface TailwindModalConfig<D = unknown> {
  data?: D; // injected through TAILWIND_MODAL_DATA
  size?: TailwindSize; // 'xs' | 'sm' | 'md' | 'lg' | 'xl'  (default: 'md')
  showCloseButton?: boolean; // × button in the top right corner (default: true)
  closeOnBackdrop?: boolean; // click outside to close (default: true)
  closeOnEscape?: boolean; // Escape to close (default: true)
}
```

The `tailwind-modal` component also exposes `closeLabel`, the accessible name of the close button, defaulting to `TAILWIND_LABELS.close`.

## Accessibility

While open, the dialog:

- traps focus inside the panel (`cdkTrapFocus`) and returns it to the opener on close;
- locks scrolling on `<body>`;
- links the title to the dialog through `aria-labelledby`;
- closes on Escape (`closeOnEscape`).

The footer hides itself when nothing is projected into the `tailwind-modal-footer` slot.

## Multiple open dialogs

Every `open()` call creates an isolated injector with its own `TailwindModalRef` instance, so several dialogs can be open at once, each component receiving its own ref without conflicts.
