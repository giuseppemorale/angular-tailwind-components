# NumberInput

`TailwindNumberInput` is the numeric field with increment and decrement buttons.

`tailwind-input type="number"` leaves the native spinners in place: tiny, unstylable and missing on mobile. Here the buttons are real elements, the value is clamped to `min`/`max`, and the form holds a `number | null` rather than a numeric string.

---

## Import

```typescript
import { ReactiveFormsModule, TailwindNumberInput } from 'angular-tailwind-components';
```

## Keyboard

Arrow Up and Arrow Down inside the field step the value by `step`, without touching the buttons.
