# NumberInput

`TailwindNumberInput` è il campo numerico con pulsanti di incremento e decremento.

`tailwind-input type="number"` lascia gli spinner nativi: minuscoli, non stilabili e assenti su mobile. Qui i pulsanti sono reali, il valore è vincolato a `min`/`max` e resta un `number | null` nel form, non una stringa numerica.

---

## Utilizzo

```typescript
@Component({
  imports: [TailwindNumberInput, ReactiveFormsModule],
  template: ` <tailwind-number-input label="Quantità" [min]="0" [max]="99" [formControl]="form.controls.quantity" />`
})
export class ExampleComponent {}
```
