# Pagination

`TailwindPagination` handles page navigation, with a configurable textual summary.

---

## Import

```typescript
import { TailwindPagination } from 'angular-tailwind-components';
```

## Properties

<ArgTypes of={PaginationStories} />

### Injection tokens

| Token                         | Type                     | Description                                                     |
| ----------------------------- | ------------------------ | --------------------------------------------------------------- |
| `TAILWIND_PAGINATION_SUMMARY` | `InjectionToken<string>` | Default of `summary` when the input is not set in the template. |

---

## Example

<Canvas of={PaginationStories.Pagination} />

```typescript
@Component({
  imports: [TailwindPagination],
  template: ` <tailwind-pagination
    [totalItems]="50"
    [pageSize]="10"
    [currentPage]="1"
    ariaLabel="Pagination"
    summary="Visualizzati {start}-{end} di {total}" />`
})
export class ExampleComponent {}
```

### Global default: `TAILWIND_PAGINATION_SUMMARY`

The **`TAILWIND_PAGINATION_SUMMARY`** token (`InjectionToken<string>`) sets the **default text** of the **`summary`** input for every **`tailwind-pagination`** under that provider, whenever the template does not pass **`summary`** itself. Without the token the default is **`'Showing {start}-{end} of {total}'`**. The **`{start}`**, **`{end}`** and **`{total}`** placeholders mean the same as in the **`summary`** input.

To avoid repeating the string on every instance, register the provider **once** at application level, next to the router, the HTTP client and so on.

```typescript
import { TAILWIND_PAGINATION_SUMMARY } from 'angular-tailwind-components';

bootstrapApplication(AppComponent, {
  providers: [{ provide: TAILWIND_PAGINATION_SUMMARY, useValue: 'Visualizzati {start}-{end} di {total}' }]
});
```

Setting **`[summary]="…"`** on a single instance **wins** over the token default.
