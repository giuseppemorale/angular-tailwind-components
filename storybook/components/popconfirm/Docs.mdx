# Popconfirm

`TailwindPopconfirm` è la conferma inline ancorata al controllo che l&apos;ha richiesta — "Eliminare questa riga?" con Sì/No, senza il peso di un modal.

Un modal è giusto per una decisione che merita tutto lo schermo; per un cancella-riga è invasivo. Qui il focus resta vicino all&apos;azione, il pulsante sicuro riceve il focus per primo e Escape annulla.

---

## Utilizzo

```typescript
@Component({
  imports: [TailwindPopconfirm, TailwindButton],
  template: ` <tailwind-button color="danger" #btn (click)="ask.toggle(btn)">Elimina</tailwind-button>
    <tailwind-popconfirm #ask message="Eliminare la riga?" (confirmed)="remove()" />`
})
export class ExampleComponent {
  remove(): void {}
}
```
