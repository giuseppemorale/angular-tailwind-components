# Popover

`TailwindPopover` è un pannello di contenuto arbitrario ancorato a un trigger: quello che il tooltip è per il testo, questo lo è per il markup — form, elenchi, dettagli.

Posizionamento, ribaltamento sul viewport, chiusura al click esterno ed Escape arrivano dal CDK overlay; il trigger mantiene `aria-expanded` e `aria-controls` puntati al pannello.

---

## Utilizzo

```typescript
@Component({
  imports: [TailwindPopover, TailwindButton],
  template: ` <tailwind-button #trigger (click)="pop.toggle(trigger)">Dettagli</tailwind-button>
    <tailwind-popover #pop title="Dettagli" [showCloseButton]="true">
      <p>Qualsiasi contenuto.</p>
    </tailwind-popover>`
})
export class ExampleComponent {}
```

## Metodi

| Metodo           | Descrizione                                               |
| ---------------- | --------------------------------------------------------- |
| `open(anchor)`   | Apre ancorato all&apos;elemento o all&apos;evento passato |
| `close()`        | Chiude e riporta il focus al trigger se era nel pannello  |
| `toggle(anchor)` | Apre o chiude                                             |
