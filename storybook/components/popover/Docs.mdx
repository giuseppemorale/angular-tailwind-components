# Popover

`TailwindPopover` anchors a panel of arbitrary content to a trigger: what the tooltip is for text, this is for markup — forms, lists, details.

Positioning, viewport flipping, outside-click dismissal and Escape come from the CDK overlay; the trigger keeps `aria-expanded` and `aria-controls` pointed at the panel.

---

## Example

```typescript
@Component({
  imports: [TailwindPopover, TailwindButton],
  template: ` <tailwind-button #trigger (click)="pop.toggle(trigger)">Dettagli</tailwind-button>
    <tailwind-popover #pop title="Dettagli" [showCloseButton]="true">
      <p>Qualsiasi contenuto.</p>
    </tailwind-popover>`
})
export class ExampleComponent {}
```

## Methods

| Method           | Description                                                        |
| ---------------- | ------------------------------------------------------------------ |
| `open(anchor)`   | Opens anchored to the element or event passed in                   |
| `close()`        | Closes and returns focus to the trigger if it was inside the panel |
| `toggle(anchor)` | Opens or closes                                                    |
