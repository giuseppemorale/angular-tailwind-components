# Progress bar

`TailwindProgressBar` shows percentage progress, an indeterminate mode and the usual styling options.

---

## Import

```typescript
import { TailwindProgressBar } from 'angular-tailwind-components';
```

## Example

<Canvas of={ProgressBarStories.ProgressBar} />

```typescript
@Component({
  imports: [TailwindProgressBar],
  template: ` <tailwind-progress-bar
    [value]="65"
    label="Upload progress"
    [showLabel]="true"
    [showValue]="true"
    color="primary"
    size="md"
    [indeterminate]="false"
    [striped]="false" />`
})
export class ExampleComponent {}
```

## Indeterminate

`indeterminate` means _we do not know how far along we are_: `value` no longer measures anything, so
the percentage is not printed even with `showValue` on, and `aria-valuenow` is removed — it is exactly
the absence of that attribute that makes assistive technology announce the progress as unknown. When
nothing is left to show, the label row is not rendered at all, so it leaves no margin behind.
