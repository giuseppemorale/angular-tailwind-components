# Radio group

`TailwindRadioGroup` groups radio options in a vertical or horizontal layout, with form integration.

---

## Import

```typescript
import { TailwindRadioGroup } from 'angular-tailwind-components';
```

## Example

<Canvas of={RadioStories.RadioGroup} />

```typescript
@Component({
  imports: [TailwindRadioGroup],
  template: ` <tailwind-radio-group
    label="Plan"
    [options]="options"
    size="md"
    orientation="vertical"
    [(value)]="selected" />`
})
export class ExampleComponent {
  selected = 'free';
  options = [
    { value: 'free', label: 'Free' },
    { value: 'pro', label: 'Pro' }
  ];
}
```
