# Rating

`TailwindRating` is a star rating, editable or read-only.

It is exposed as a `slider` rather than a row of buttons: that is the ARIA pattern for choosing a value in an ordered range, and it gives arrows plus Home/End for free instead of forcing a Tab stop on every star.

---

## Import

```typescript
import { ReactiveFormsModule, TailwindRating } from 'angular-tailwind-components';
```

## Keyboard

| Key               | Effect                                 |
| ----------------- | -------------------------------------- |
| Arrow Right / Up  | +1 star                                |
| Arrow Left / Down | −1 star                                |
| Home              | Clears, or 1 when `clearable` is false |
| End               | Maximum                                |
