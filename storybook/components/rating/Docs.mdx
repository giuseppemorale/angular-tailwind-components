# Rating

`TailwindRating` è la valutazione a stelle, modificabile o in sola lettura.

È esposto come `slider` invece che come fila di bottoni: è il pattern ARIA per scegliere un valore in un intervallo ordinato e dà gratis frecce e Home/End, invece di costringere a passare in Tab su ogni stella.

---

## Utilizzo

```typescript
@Component({
  imports: [TailwindRating, ReactiveFormsModule],
  template: `<tailwind-rating [formControl]="form.controls.score" ariaLabel="Valutazione" />`
})
export class ExampleComponent {}
```

## Tastiera

| Tasto                  | Effetto                             |
| ---------------------- | ----------------------------------- |
| Freccia destra / su    | +1 stella                           |
| Freccia sinistra / giù | −1 stella                           |
| Home                   | Azzera (o 1 se `clearable` è false) |
| End                    | Massimo                             |
