# SegmentedControl

`TailwindSegmentedControl` mostra affiancate poche scelte mutuamente esclusive. Usalo al posto di una select quando le opzioni sono due-cinque e vederle tutte insieme conta.

È implementato come **radio group** ARIA, non come tablist: la scelta è un valore, non una vista, quindi funziona con `formControl` e `ngModel`.

---

## Utilizzo

```typescript
@Component({
  imports: [TailwindSegmentedControl, ReactiveFormsModule],
  template: ` <tailwind-segmented-control label="Vista" [options]="views" [formControl]="form.controls.view" />`
})
export class ExampleComponent {
  readonly views = [
    { value: 'list', label: 'Elenco' },
    { value: 'grid', label: 'Griglia' }
  ];
}
```

## Tastiera

| Tasto      | Effetto                                                                                                |
| ---------- | ------------------------------------------------------------------------------------------------------ |
| Frecce     | Sposta la selezione al segmento precedente/successivo, saltando i disabilitati e ciclando agli estremi |
| Home / End | Primo / ultimo segmento abilitato                                                                      |

Il gruppo espone un solo tab stop: Tab vi entra e ne esce, le frecce si muovono all&apos;interno.
