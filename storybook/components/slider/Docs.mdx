# Slider

`TailwindSlider` is an accessible slider — dragging, keyboard, ARIA. It supports a single value or a two-thumb **range**, horizontal or vertical layout, steps and optional ticks.

It implements **`ControlValueAccessor`**: the value is a `number`, or `[number, number]` when `range` is `true` — the exported `TailwindSliderValue` type.

---

## Import

```typescript
import { FormsModule, TailwindSlider } from 'angular-tailwind-components';
```

## Example

<Canvas of={SliderStories.Slider} />

```typescript
import { Component } from '@angular/core';
import { FormsModule } from '@angular/forms';
import { TailwindSlider } from 'angular-tailwind-components';

@Component({
  imports: [FormsModule, TailwindSlider],
  template: `
    <tailwind-slider [(ngModel)]="volume" [min]="0" [max]="100" [step]="1" />
    <tailwind-slider [(ngModel)]="window" [range]="true" [min]="0" [max]="24" [step]="1" />
  `
})
export class ExampleComponent {
  volume = 50;
  window: [number, number] = [8, 18];
}
```

Disabling: the **`disabled`** attribute on the component, or the disabled state of the form control through `setDisabledState`.

## Form value

| Mode   | Value type (`ngModel` / `writeValue`)  |
| ------ | -------------------------------------- |
| Single | `number`                               |
| Range  | `[number, number]`, ordered internally |
