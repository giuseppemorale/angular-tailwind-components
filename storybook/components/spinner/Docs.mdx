# Spinner

`TailwindSpinner` signals loading with an animated SVG, a semantic color and a label orientation.

---

## Import

```typescript
import { TailwindSpinner } from 'angular-tailwind-components';
```

## Example

<Canvas of={SpinnerStories.Spinner} />

```typescript
@Component({
  imports: [TailwindSpinner],
  template: ` <tailwind-spinner
    icon="arrow-path"
    size="md"
    color="primary"
    label=""
    ariaLabel="Loading"
    orientation="horizontal" />`
})
export class ExampleComponent {}
```
