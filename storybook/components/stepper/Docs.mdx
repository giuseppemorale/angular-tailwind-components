# Stepper

`TailwindStepper` organises content into steps; each step is a `tailwind-step` with a label and a description.

---

## Import

```typescript
import { TailwindInput, TailwindStep, TailwindStepper } from 'angular-tailwind-components';
```

### `TailwindStepper (tailwind-stepper)`

<ArgTypes of={StepperStories} />

### `TailwindStep (tailwind-step)`

<ArgTypes of={TailwindStep} />

The `completed` and `isActive` states are managed internally by the stepper.

## Example

<Canvas of={StepperStories.Stepper} />

```typescript
@Component({
  imports: [TailwindStepper, TailwindStep, TailwindInput],
  template: ` <tailwind-stepper>
    <tailwind-step label="Account" description="Create your account">
      <tailwind-input label="Email" />
    </tailwind-step>
    <tailwind-step label="Done" description="Finish">
      <p>Complete.</p>
    </tailwind-step>
  </tailwind-stepper>`
})
export class ExampleComponent {}
```
