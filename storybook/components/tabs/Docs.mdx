# Tabs

`TailwindTabGroup` and `TailwindTab` define tabs with projected content and a two-way active index.

---

## Import

```typescript
import { TailwindTab, TailwindTabGroup } from 'angular-tailwind-components';
```

## Example

<Canvas of={TabsStories.Tabs} />

```typescript
@Component({
  imports: [TailwindTabGroup, TailwindTab],
  template: ` <tailwind-tab-group color="primary" ariaLabel="Example" [scrollable]="false" [(activeIndex)]="index">
    <tailwind-tab label="Overview">Overview content</tailwind-tab>
    <tailwind-tab label="Details">Details content</tailwind-tab>
  </tailwind-tab-group>`
})
export class ExampleComponent {
  index = 0;
}
```
