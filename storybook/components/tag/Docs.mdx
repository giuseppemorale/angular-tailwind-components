# Tag

`TailwindTag` è un’etichetta stile “pill” uppercase per stati e categorie.

---

## Utilizzo

```typescript
@Component({
  imports: [TailwindTag],
  template: `<tailwind-tag color="secondary">Label</tailwind-tag>`
})
export class ExampleComponent {}
```

<Canvas of={TagStories.Tags} />

## Varianti

`kind` sceglie il peso della superficie, con metriche identiche fra le tre varianti. La stessa triade
è disponibile su `tailwind-badge`, `tailwind-chip` e `tailwind-alert`.
