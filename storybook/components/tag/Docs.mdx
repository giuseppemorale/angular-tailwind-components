# Tag

`TailwindTag` is an uppercase pill label for statuses and categories.

---

## Import

```typescript
import { TailwindTag } from 'angular-tailwind-components';
```

## Properties

<ArgTypes of={TagStories} />

The tag content is projected into the body of the component.

---

## Example

<Canvas of={TagStories.Tags} />

```typescript
@Component({
  imports: [TailwindTag],
  template: `<tailwind-tag color="secondary">Label</tailwind-tag>`
})
export class ExampleComponent {}
```

## Variants

`kind` picks the weight of the surface, with identical metrics across the three variants. The same
triad is available on `tailwind-badge`, `tailwind-chip` and `tailwind-alert`.
