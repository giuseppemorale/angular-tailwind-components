# Textarea

`TailwindTextarea` is a multi-line field with label, error states, resize options and `ControlValueAccessor` integration for both template-driven and reactive forms.

---

## Import

```typescript
import { TailwindTextarea } from 'angular-tailwind-components';
```

## Example

<Canvas of={TextareaStories.Textarea} />

```typescript
@Component({
  imports: [TailwindTextarea],
  template: ` <tailwind-textarea
    label="Description"
    placeholder="Enter your text"
    [rows]="5"
    resize="vertical"
    size="md"
    [(value)]="description" />`
})
export class ExampleComponent {
  description = '';
}
```
