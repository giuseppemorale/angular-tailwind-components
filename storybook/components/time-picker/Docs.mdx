# Time picker

`TailwindTimePicker` picks a time. It is a `ControlValueAccessor` whose value is a string in **`HH:mm`** format, e.g. `"14:30"`.

It shows a single read-only field with a clock icon; clicking it opens a panel with **two `<select>`** controls (hours 00–23, minutes 00–59) and two buttons:

- **Now** — sets the draft to the current time
- **Apply** — commits the selection, updates the value and closes the panel

Closing the panel with a second click on the field discards the draft.

---

## Import

```typescript
import { TailwindTimePicker } from 'angular-tailwind-components';
```

## Properties

<ArgTypes of={TimePickerStories} />

### Injection token

| Token                        | Type                       | Values          | Default |
| ---------------------------- | -------------------------- | --------------- | ------- |
| `TAILWIND_DATETIME_LANGUAGE` | `TailwindDatetimeLanguage` | `'it'` · `'en'` | `'it'`  |

The CVA value is a **`string`** in `HH:mm` format. `writeValue` accepts a valid string, an empty string or `undefined`, which resets to `''`.

## Interface language

The placeholder and the button labels (**Now**, **Apply**) follow the **`TAILWIND_DATETIME_LANGUAGE`** token.

Supported values: **`'it'`** or **`'en'`**. Without the token the component falls back to **`'it'`**.

### Recommended setup: global provider

**Standalone application** (`app.config.ts`):

```typescript
import { ApplicationConfig } from '@angular/core';
import { TAILWIND_DATETIME_LANGUAGE } from 'angular-tailwind-components';

export const appConfig: ApplicationConfig = {
  providers: [
    { provide: TAILWIND_DATETIME_LANGUAGE, useValue: 'it' }
    // …altri provider
  ]
};
```

**Direct bootstrap** (`main.ts`) or **root module** (`AppModule`): the same `{ provide: TAILWIND_DATETIME_LANGUAGE, useValue: 'it' }` object in the `providers` array.
