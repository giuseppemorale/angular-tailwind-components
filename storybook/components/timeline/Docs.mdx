# Timeline

`TailwindTimeline` mostra una sequenza ordinata di eventi: feed di attività, tracciamento ordini, audit trail.

È reso come `<ol>`: l&apos;ordine porta significato, quindi uno screen reader deve annunciarlo come elenco numerato e non come una pila di div. Linea di collegamento e pallini sono decorativi e nascosti agli screen reader.

---

## Utilizzo

```typescript
@Component({
  imports: [TailwindTimeline, TailwindTimelineItem],
  template: ` <tailwind-timeline ariaLabel="Storico ordine">
    <tailwind-timeline-item title="Ordine ricevuto" time="09:12" color="success" icon="check">
      Pagamento autorizzato.
    </tailwind-timeline-item>
    <tailwind-timeline-item title="Spedito" time="14:05" [last]="true" />
  </tailwind-timeline>`
})
export class ExampleComponent {}
```
