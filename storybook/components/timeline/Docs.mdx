# Timeline

`TailwindTimeline` renders an ordered sequence of events: activity feeds, order tracking, audit trails.

It renders as an `<ol>`: the order carries meaning, so a screen reader must announce it as an ordered list rather than a stack of divs. The connecting line and the dots are decorative and hidden from assistive technology.

---

## Import

```typescript
import { TailwindTimeline, TailwindTimelineItem } from 'angular-tailwind-components';
```
