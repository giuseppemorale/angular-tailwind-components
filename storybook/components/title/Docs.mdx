# Title

`TailwindTitle` rende un titolo semantico (`h1`–`h6`) con testo obbligatorio e, opzionalmente, un’icona Heroicons outline **prima** del testo.

---

## Utilizzo

```typescript
@Component({
  imports: [TailwindTitle],
  template: `
    <tailwind-title titleTag="h1" text="Dashboard" class="text-primary-700" />
    <tailwind-title titleTag="h2" text="Impostazioni" icon="cog-6-tooth" />
  `
})
export class ExampleComponent {}
```

## Scala titoli con defineTheme

Tipografia e dimensione icona per ogni `titleTag` sono configurabili a livello app con **`defineTheme({ TITLE_SCALE: … })`** (token `TAILWIND_TITLE_SCALE`). I valori non specificati restano quelli di default della libreria (`DEFAULT_TAILWIND_TITLE_SCALE`).

```typescript
import { defineTheme } from 'angular-tailwind-components';

defineTheme({
  TITLE_SCALE: {
    h1: { classes: 'text-4xl font-extrabold text-primary-800', iconSize: 36 },
    h2: { iconSize: 28 }
  }
});
```

Puoi anche fornire il token direttamente nei `providers` del componente o del modulo.
