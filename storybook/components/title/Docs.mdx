# Title

`TailwindTitle` renders a semantic heading (`h1`–`h6`) with required text and, optionally, a Heroicons outline icon **before** the text.

---

## Import

```typescript
import { TailwindTitle } from 'angular-tailwind-components';
```

## Properties

<ArgTypes of={TitleStories} />

`:host { display: contents }` keeps the real heading element as the one that counts for layout.

## Title scale with `provideTailwindConfig`

Typography and icon size per `titleTag` are configurable at application level with **`provideTailwindConfig({ TITLE_SCALE: … })`** (the `TAILWIND_TITLE_SCALE` token). Anything left unspecified keeps the library default, `DEFAULT_TAILWIND_TITLE_SCALE`.

```typescript
import { provideTailwindConfig } from 'angular-tailwind-components';

provideTailwindConfig({
  TITLE_SCALE: {
    h1: { classes: 'text-4xl font-extrabold text-primary-800', iconSize: 36 },
    h2: { iconSize: 28 }
  }
});
```

The token can also be provided directly in the `providers` of a component or module.
