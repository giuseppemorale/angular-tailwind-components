# Toast

Toasts are pushed through `TailwindToastService` and rendered by the `<tailwind-toast />` container. Include that container **once**, in the template of the application root component, and toasts become available everywhere.

---

## Import

```typescript
import { TailwindToast, TailwindToastService } from 'angular-tailwind-components';
```

## Properties

### `TailwindToast (tailwind-toast)`

<ArgTypes of={TailwindToast} />

### `TailwindToastService`

A `providedIn: 'root'` service.

| Method                              | Description                              |
| ----------------------------------- | ---------------------------------------- |
| `show(config: TailwindToastConfig)` | Adds a toast and returns its numeric id. |
| `success(title, message, icon?)`    | Toast in the success color.              |
| `warning(title, message, icon?)`    | Warning toast.                           |
| `danger(title, message, icon?)`     | Danger toast.                            |
| `info(title, message, icon?)`       | Info toast.                              |
| `dismiss(id)`                       | Removes one toast by id.                 |
| `clear()`                           | Removes every toast.                     |

`TailwindToastConfig` carries the message, an optional title, an optional `TailwindHeroicon`, the `color`, the duration and whether the toast can be dismissed.

## Example

<Canvas of={ToastStories.ServiceBased} />

### 1 — Add the container to `AppComponent`

```typescript
import { Component } from '@angular/core';
import { TailwindToast } from 'angular-tailwind-components';

@Component({
  selector: 'app-root',
  imports: [TailwindToast /* …RouterOutlet, etc. */],
  template: `
    <!-- application content -->
    <tailwind-toast />
  `
})
export class AppComponent {}
```

### 2 — Push toasts from the service

Inject `TailwindToastService` anywhere and call one of its methods (`success`, `warning`, …).

```typescript
import { Component, inject } from '@angular/core';
import { TailwindToastService, TailwindButton } from 'angular-tailwind-components';

@Component({
  imports: [TailwindButton],
  template: ` <tailwind-button (click)="toast.success('Success', 'Saved!', 'check-circle')">Success</tailwind-button> `
})
export class ExampleComponent {
  toast = inject(TailwindToastService);
}
```

## Anchoring the stack

<tailwind-toast vertical="bottom" horizontal="left" />
