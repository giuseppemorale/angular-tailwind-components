# Toast

I toast sono gestiti da `TailwindToastService` e resi dal componente `<tailwind-toast />`. Va incluso **una sola volta** nel template del componente radice dell’app (ad es. `AppComponent`), così i toast sono disponibili ovunque.

---

## Utilizzo

### 1 — Aggiungi il contenitore nell’`AppComponent`

```typescript
import { Component } from '@angular/core';
import { TailwindToast } from 'angular-tailwind-components';

@Component({
  selector: 'app-root',
  imports: [TailwindToast /* …RouterOutlet, ecc. */],
  template: `
    <!-- contenuto dell’app -->
    <tailwind-toast />
  `
})
export class AppComponent {}
```

### 2 — Mostra i toast dal servizio

Da qualsiasi componente inietta `TailwindToastService` e chiama i metodi (`success`, `warning`, ecc.).

```typescript
import { Component, inject } from '@angular/core';
import { TailwindToastService, TailwindButton } from 'angular-tailwind-components';

@Component({
  imports: [TailwindButton],
  template: `
    <tailwind-button (click)="toast.success('Success', 'Saved!', 'check-circle')">Success</tailwind-button>
  `
})
export class ExampleComponent {
  toast = inject(TailwindToastService);
}
```

## `TailwindToastService`

Servizio `providedIn: 'root'`.

<table class="w-full">
  <thead>
    <tr>
      <th>Metodo</th>
      <th>Descrizione</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td><code>show(config: TailwindToastConfig)</code></td>
      <td>Aggiunge un toast; restituisce l’id numerico.</td>
    </tr>
    <tr>
      <td><code>success(title, message, icon?)</code></td>
      <td>Toast con colore success.</td>
    </tr>
    <tr>
      <td><code>warning(title, message, icon?)</code></td>
      <td>Toast warning.</td>
    </tr>
    <tr>
      <td><code>danger(title, message, icon?)</code></td>
      <td>Toast danger.</td>
    </tr>
    <tr>
      <td><code>info(title, message, icon?)</code></td>
      <td>Toast info.</td>
    </tr>
    <tr>
      <td><code>dismiss(id)</code></td>
      <td>Rimuove un toast per id.</td>
    </tr>
    <tr>
      <td><code>clear()</code></td>
      <td>Rimuove tutti i toast.</td>
    </tr>
  </tbody>
</table>

La configurazione (`TailwindToastConfig`) supporta messaggio, titolo opzionale, icona opzionale (`TailwindHeroicon`), `color`, durata e dismissibile (vedi sorgente).
