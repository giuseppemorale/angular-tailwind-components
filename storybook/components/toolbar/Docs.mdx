# Toolbar

`TailwindToolbar` is a horizontal application bar or a vertical side rail. The central **menu** is a `TailwindMenuItem[]` array; logo and trailing actions stay **content projection**, through the `tailwind-toolbar-logo` and `tailwind-toolbar-end` attributes on plain elements such as `<div tailwind-toolbar-logo>`.

## Example

<Canvas meta={ToolbarStories} of={ToolbarStories.Horizontal} />

```typescript
import { Component } from '@angular/core';
import { TailwindButton, TailwindMenuItem, TailwindToolbar } from 'angular-tailwind-components';

@Component({
  imports: [TailwindToolbar, TailwindButton],
  template: `
    <tailwind-toolbar [menu]="menu" (onMenuSelect)="onNav($event)">
      <div tailwind-toolbar-logo>Brand</div>
      <div tailwind-toolbar-end>
        <tailwind-button>Account</tailwind-button>
      </div>
    </tailwind-toolbar>
  `
})
export class ExampleComponent {
  menu: TailwindMenuItem[] = [
    { label: 'Home', value: 'home' },
    { label: 'Docs', value: 'docs' }
  ];

  onNav(item: TailwindMenuItem) {
    console.log(item.value);
  }
}
```

With **orientation** `vertical` the menu entries stack in a column and `divider: true` produces a horizontal separator. In the horizontal bar the divider is a vertical line between entries.

An entry carrying **`items`** opens a **`tailwind-menu`** on click: below the entry in the horizontal bar, to its right in the vertical rail. **`onMenuSelect`** fires only for leaf entries, those without `items`.

### Menu entries (`TailwindMenuItem`)

On top of `label`, `icon`, `value`, `disabled`, `divider` and `items`, every toolbar menu entry can define:

| Field             | Type                                     | Toolbar default | Description                                                                                                        |
| ----------------- | ---------------------------------------- | --------------- | ------------------------------------------------------------------------------------------------------------------ |
| `tooltip`         | `string`                                 | —               | Tooltip text on hover. Useful on **icon-only** entries, where no `label` is visible.                               |
| `tooltipPosition` | `'top' \| 'bottom' \| 'left' \| 'right'` | `'right'`       | Tooltip position relative to the button. `right` suits a left rail; use `left` when the toolbar sits on the right. |

Icon-only vertical rail:

```typescript
menu: TailwindMenuItem[] = [
  { icon: 'home', value: 'home', tooltip: 'Home' },
  { icon: 'bell', value: 'notifications', tooltip: 'Notifiche' },
  { icon: 'cog-6-tooth', value: 'settings', tooltip: 'Impostazioni', tooltipPosition: 'left' }
];
```

## Content projection

| Slot | Attribute               | Description                                       |
| ---- | ----------------------- | ------------------------------------------------- |
| Logo | `tailwind-toolbar-logo` | Brand / title area, on the left or at the top.    |
| End  | `tailwind-toolbar-end`  | Secondary actions, on the right or at the bottom. |
