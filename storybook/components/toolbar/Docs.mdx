# Toolbar

`TailwindToolbar` è una barra applicativa orizzontale o un rail laterale verticale. Il **menu** centrale è un array `TailwindMenuItem[]`; logo e azioni finali restano **content projection** con attributi `[tailwind-toolbar-logo]` e `[tailwind-toolbar-end]` su elementi nativi (es. `<div tailwind-toolbar-logo>`).

---

## Utilizzo

```typescript
import { Component } from '@angular/core';
import { TailwindButton, TailwindMenuItem, TailwindToolbar } from 'angular-tailwind-components';

@Component({
  imports: [TailwindToolbar, TailwindButton],
  template: `
    <tailwind-toolbar [menu]="menu" (onMenuSelect)="onNav($event)">
      <div tailwind-toolbar-logo>Brand</div>
      <div tailwind-toolbar-end>
        <tailwind-button>Account</tailwind-button>
      </div>
    </tailwind-toolbar>
  `
})
export class ExampleComponent {
  menu: TailwindMenuItem[] = [
    { label: 'Home', value: 'home' },
    { label: 'Docs', value: 'docs' }
  ];

  onNav(item: TailwindMenuItem) {
    console.log(item.value);
  }
}
```

Con **orientation** `vertical`, le voci del menu sono in colonna; con `divider: true` su un elemento si ottiene un separatore orizzontale. In orizzontale il divider è una linea verticale tra le voci.

Una voce con **`items`** (sottomenu) apre un **`tailwind-menu`** al click: sotto la voce in toolbar orizzontale, a destra nel rail verticale. **`onMenuSelect`** viene emesso solo per le voci foglia (senza `items`).

### Voci menu (`TailwindMenuItem`)

Oltre a `label`, `icon`, `value`, `disabled`, `divider` e `items`, ogni voce del menu toolbar può definire:

| Campo | Tipo | Default toolbar | Descrizione |
|-------|------|-----------------|-------------|
| `tooltip` | `string` | — | Testo del tooltip al passaggio del mouse. Utile con voci **solo icona** (senza `label` visibile). |
| `tooltipPosition` | `'top' \| 'bottom' \| 'left' \| 'right'` | `'right'` | Posizione del tooltip rispetto al pulsante. Default `right` per rail a sinistra; usa `left` se la toolbar è a destra. |

Esempio rail verticale solo icone:

```typescript
menu: TailwindMenuItem[] = [
  { icon: 'home', value: 'home', tooltip: 'Home' },
  { icon: 'bell', value: 'notifications', tooltip: 'Notifiche' },
  { icon: 'cog-6-tooth', value: 'settings', tooltip: 'Impostazioni', tooltipPosition: 'left' }
];
```
