# Tooltip

`TailwindTooltipDirective` (`selector: '[tooltip], [tailwindTooltip]'`) mostra un overlay al passaggio del mouse o al focus sull’elemento host.

Il testo può arrivare da entrambi i selettori: `[tooltip]` è quello storico, `[tailwindTooltip]` è la variante prefissata da preferire nel codice nuovo. Se sono valorizzati entrambi vince quello prefissato.

---

## Utilizzo

```typescript
@Component({
  imports: [TailwindTooltipDirective, TailwindButton],
  template: ` <tailwind-button [tailwindTooltip]="'Hello'" [tooltipPosition]="'top'">Hover me</tailwind-button>`
})
export class ExampleComponent {}
```
