# Tooltip

`TailwindTooltipDirective` (`selector: '[tooltip], [tailwindTooltip]'`) shows an overlay on hover or focus of the host element.

The text can come from either selector: `[tooltip]` is the original one, `[tailwindTooltip]` the prefixed variant to prefer in new code. When both are set, the prefixed one wins.

---

## Import

```typescript
import { TailwindButton, TailwindTooltipDirective } from 'angular-tailwind-components';
```
