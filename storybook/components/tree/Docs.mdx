# Tree

`TailwindTree` is the hierarchical list: file trees, category pickers, nested navigation.

It follows the ARIA **tree** pattern: a single tab stop for the whole widget with a roving `tabindex`, arrows to walk and open branches, Home/End to jump. Rendering is flattened, so only visible rows exist in the DOM and a deep tree stays light.

## Keyboard

| Key             | Effect                                                  |
| --------------- | ------------------------------------------------------- |
| Arrow Down / Up | Next / previous visible row                             |
| Arrow Right     | Opens a closed branch, then steps into it               |
| Arrow Left      | Closes an open branch, otherwise moves up to the parent |
| Home / End      | First / last visible row                                |
| Enter / Space   | Selects the row                                         |
