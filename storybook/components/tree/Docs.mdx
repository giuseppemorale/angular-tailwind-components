# Tree

`TailwindTree` è l&apos;elenco gerarchico: alberi di file, selettori di categorie, navigazioni annidate.

Segue il pattern ARIA **tree**: un solo tab stop per l&apos;intero widget con `tabindex` mobile, frecce per percorrere e aprire i rami, Home/End per saltare. Il rendering è appiattito, così nel DOM esistono solo le righe visibili e un albero profondo resta leggero.

---

## Utilizzo

```typescript
@Component({
  imports: [TailwindTree],
  template: `<tailwind-tree [nodes]="nodes" ariaLabel="File" (nodeSelect)="open($event)" />`
})
export class ExampleComponent {
  readonly nodes: TailwindTreeNode[] = [
    { key: 'src', label: 'src', icon: 'folder', children: [{ key: 'main.ts', label: 'main.ts' }] }
  ];
  open(node: TailwindTreeNode): void {}
}
```

## Tastiera

| Tasto            | Effetto                                              |
| ---------------- | ---------------------------------------------------- |
| Freccia giù / su | Riga successiva / precedente tra quelle visibili     |
| Freccia destra   | Apre il ramo chiuso, poi vi entra                    |
| Freccia sinistra | Chiude il ramo aperto, altrimenti risale al genitore |
| Home / End       | Prima / ultima riga visibile                         |
| Invio / Spazio   | Seleziona la riga                                    |
