# Upload

`TailwindUpload` picks files through a **drag-and-drop area** or a **button** that opens the native file picker. The form value is a **data URL** (`data:<type>;base64,…`), usable directly in `<img [src]>`. Without a form model, read the raw `File` objects from the **`filesSelected`** output.

---

## Import

```typescript
import { ReactiveFormsModule, TailwindUpload } from 'angular-tailwind-components';
```

## Example

<Canvas of={UploadStories.Area} />

### Form / `[(value)]` (base64 data URL)

```typescript
@Component({
  imports: [TailwindUpload, ReactiveFormsModule],
  template: `
    <form [formGroup]="form">
      <tailwind-upload label="Avatar" variant="area" accept="image/*" formControlName="avatarDataUrl" />
    </form>
  `
})
export class ExampleComponent {
  form = new FormGroup({
    avatarDataUrl: new FormControl('')
  });
}
```

### Output only (`File[]`)

```typescript
@Component({
  imports: [TailwindUpload],
  template: `
    <tailwind-upload variant="button" buttonLabel="Choose files" [multiple]="true" (filesSelected)="onFiles($event)" />
  `
})
export class ExampleComponent {
  onFiles(files: File[]) {
    /* HTTP upload, etc. — without touching the FormControl */
  }
}
```

With **`multiple`**, the model / `FormControl` holds the data URL of the **first file only**; every picked file is still emitted through **`filesSelected`**.
