# Icons

Le icone sono **[Heroicons](https://heroicons.com/outline)** in variante **outline** (24×24), licenza **MIT** (Tailwind Labs). Ogni SVG è servito con **larghezza e altezza intrinseche 64×64** e `viewBox` 24×24 così si scalano da **16 a 64 px** tramite l’attributo **`size`** del componente.

## Uso in TypeScript

Importa il tipo e l’array dei nomi dalla libreria:

```typescript
import type { TailwindHeroicon } from 'angular-tailwind-components';
import { TAILWIND_HEROICON_NAMES } from 'angular-tailwind-components';

const icon: TailwindHeroicon = 'bell';
```

Per ogni icona la **stringa da usare** è il nome in **kebab-case** come su [heroicons.com/outline](https://heroicons.com/outline), ad esempio `'bell'` oppure `'cog-6-tooth'`.

## Componente `tailwind-icon`

Per mostrare un’icona usa **`TailwindIcon`** con:

- **`icon`**: `TailwindHeroicon` (obbligatorio)
- **`size`**: numero **pixel** per larghezza e altezza (**16–64**, valori fuori range vengono clampati); se omesso usa il token **`TAILWIND_ICON_SIZE`** se presente, altrimenti **24**
- **`class`**: classi Tailwind applicate al glifo interno (es. `text-success-600`, `shrink-0`); le utility `text-*` impostano il colore dell’icona

Il componente carica **`/tailwind-icons/<nome>.svg`** come maschera CSS (URL dalla root del sito che serve l’app). Le SVG non sono incorporate nel bundle JS: il browser le scarica come risorse statiche.

```typescript
import { TailwindIcon } from 'angular-tailwind-components';

@Component({
  imports: [TailwindIcon],
  template: `<tailwind-icon icon="bell" [size]="16" />`
})
export class ExampleComponent {}
```

## Build della libreria e pacchetto npm

Prima di **`npm run build`** viene eseguito **`node scripts/copy-icons.js sync`**, che rigenera **`public/tailwind-icons/*.svg`** e **`models/icons.ts`** da `@iconify-json/heroicons`. Subito dopo la compilazione, **`node scripts/copy-icons.js dist`** copia gli SVG nel pacchetto pubblicato in **`tailwind-icons/`** (accanto a `fesm2022`, ecc.).

## App che usa la libreria (build di produzione)

Nel **`angular.json`** (target **`build`** dell’app) aggiungi gli asset così le richieste a **`/tailwind-icons/nome.svg`** risolvono correttamente:

```json
"assets": [
  {
    "glob": "**/*",
    "input": "node_modules/angular-tailwind-components/tailwind-icons",
    "output": "/tailwind-icons"
  }
]
```

Il path **`input`** è relativo alla root del workspace dell’app. In sviluppo **`ng serve`** copia gli stessi file nella cartella di output con prefisso **`/tailwind-icons/`**.

## Dimensione predefinita: `TAILWIND_ICON_SIZE`

Il token **`TAILWIND_ICON_SIZE`** (`InjectionToken<number>`) imposta il **default** di **`size`** su tutte le **`tailwind-icon`** dell’albero che ricevono quel provider. Se il token **non** è fornito, il default è **24** (px).

```typescript
import { bootstrapApplication } from '@angular/platform-browser';
import { TAILWIND_ICON_SIZE } from 'angular-tailwind-components';
import { AppComponent } from './app.component';

bootstrapApplication(AppComponent, {
  providers: [{ provide: TAILWIND_ICON_SIZE, useValue: 20 }]
});
```

Puoi anche limitarlo a una parte dell’app con **`providers`** su un componente contenitore:

```typescript
@Component({
  selector: 'app-settings-shell',
  imports: [TailwindIcon],
  providers: [{ provide: TAILWIND_ICON_SIZE, useValue: 20 }],
  template: `<tailwind-icon icon="cog-6-tooth" />`
})
export class SettingsShellComponent {}
```

Passare esplicitamente **`[size]`** sulla singola icona ha sempre la precedenza sul valore del token.

## Percorsi dei file SVG

Nella repo della libreria gli SVG sorgente stanno in **`public/tailwind-icons/`** — un file `.svg` per ogni nome in `TailwindHeroicon`. Nel pacchetto npm sono nella cartella **`tailwind-icons/`**.
